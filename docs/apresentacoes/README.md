# Apresentações do sistema

## Arquivos

- `apresentacao-institucional.html`: apresentação completa em 16:9, com 8 slides.
- `apresentacao-divulgacao.html`: apresentação curta em 4:5, com 6 peças adequadas para divulgação e carrossel.
- `apresentacao-institucional.pdf`: versão pronta para apresentar ou enviar.
- `apresentacao-divulgacao.pdf`: versão pronta para divulgação.
- `preview-institucional.png` e `preview-divulgacao.png`: prévias das capas.

## Como usar

Abra o arquivo HTML no navegador. Use as setas do teclado, Page Up/Page Down ou os botões no canto inferior direito para navegar.

Para gerar PDF, use **Imprimir → Salvar como PDF**, sem margens e com gráficos de plano de fundo habilitados. A apresentação institucional deve ser impressa em orientação paisagem; a versão de divulgação, em retrato.
